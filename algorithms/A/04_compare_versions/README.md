# Сравнение версий (less-формат)

## Условие
Даны две строки с версиями. Нужно реализовать функцию, которая сравнит версии между собой и вернёт ответ в less-формате (0, 1, -1). Каждая версия задаётся строкой следующего формата:
- буква `v`
- комбинация точек и чисел
- другие знаки не разрешены

## Пример
```
v11.22.44
v11.22.45
```
Ответ: `1`

```
v11.22.44
v11.22.44
```
Ответ: `0`

> ⚠️ По примеру `1` соответствует случаю, когда **первая версия меньше** второй (44 < 45 → 1) — это обратно стандартному `cmp`. На интервью конвенцию знака стоит уточнить.
