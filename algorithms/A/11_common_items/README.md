# Товары, представленные у каждого продавца

## Условие
Имеется информация о товарах, которыми торгуют продавцы на Авито. Нужно определить
товары, которые есть у КАЖДОГО продавца — то есть пересечение списков товаров всех
продавцов.

## Пример 1
```text
# ввод
goods = [
    {sellerID: 1, items: ['варежки', 'шуба', 'валенки', 'стол', 'шапка', 'шарф', 'кофта', 'рубашка']},
    {sellerID: 2, items: ['шкаф', 'тумба', 'шапка', 'стол', 'ложка', 'кофта']},
    {sellerID: 3, items: ['вилка', 'кофта', 'тарелка', 'шарф', 'шуба', 'стол', 'кастрюля']},
    {sellerID: 4, items: ['ковер', 'тумба', 'кофта', 'пылесос', 'валенки', 'ложка', 'стол']},
]
# вывод
result = ['стол', 'кофта']
```

## Пример 2
```text
# ввод
goods = [{sellerID: 4, items: ['ковер', 'тумба', 'кофта', 'пылесос', 'валенки', 'ложка', 'стол']}]
# вывод
result = ['ковер', 'тумба', 'кофта', 'пылесос', 'валенки', 'ложка', 'стол']
```

## Алгоритмическая сложность
Время O(G·I), память O(G·I): G — число продавцов, I — среднее число товаров у продавца.
Строим множества товаров продавцов и проверяем каждый товар первого продавца на наличие
у остальных за O(1). Порядок результата совпадает с порядком товаров первого продавца.
