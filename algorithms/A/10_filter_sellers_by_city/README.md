# Фильтр продавцов по городам

## Условие
Есть объект `[ID продавца] -> [город, где он оказывает услуги]`. По списку запрошенных
городов нужно вернуть такой же объект, оставив только тех продавцов, чей город входит
в список искомых. Остальных отбросить.

## Пример
```text
# ввод
sellers = {
    1: 'Москва', 2: 'Самара', 3: 'Самара', 4: 'Тула',
    5: 'Ростов', 6: 'Казань', 7: 'Курган', 8: 'Пенза',
}
citiesToFind = ['Самара', 'Казань', 'Тула']
# вывод
{ 2: 'Самара', 3: 'Самара', 4: 'Тула', 6: 'Казань' }
```

## Алгоритмическая сложность
Время O(S + C), память O(S + C): S — число продавцов, C — число искомых городов.
Множество искомых городов (`map[string]struct{}`) даёт проверку «город нужен?» за O(1),
поэтому достаточно одного прохода по продавцам. Наивный вложенный перебор дал бы O(S·C).
