# Генерация правильных скобочных последовательностей

## Условие
Напишите функцию, генерирующую все возможные правильные скобочные последовательности из n пар скобок.

## Входные параметры
Целое число n — количество пар скобок в последовательности.

## Вывод
Список строк, представляющих собой правильные скобочные последовательности из n пар скобок.

## Пример
Ввод: `3`

Вывод:
```
[
    "((()))",
    "(()())",
    "(())()",
    "()(())",
    "()()()"
]
```
