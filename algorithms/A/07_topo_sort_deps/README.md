# Порядок импорта библиотек (топологическая сортировка)

## Условие
Есть мапа библиотек и их зависимостей. Надо распечатать библиотеки в порядке правильного импорта. Неправильный порядок — если печатаешь библиотеку, а её зависимость ещё не напечатана. Все остальные порядки правильные.

> NB: Циклических зависимостей во входных данных нет.

## Входные параметры
Глобальная мапа зависимостей.

## Выходные параметры
Печать в stdout.

## Пример
Мапа:
```text
deps = {
    "tensorflow": ["nvcc", "gpu", "linux"],
    "nvcc":       ["linux"],
    "linux":      ["core"],
    "mylib":      ["tensorflow"],
    "mylib2":     ["requests"]
}
```
Один из правильных порядков:
```
core linux nvcc gpu tensorflow mylib requests mylib2
```

## Ожидаемая алгоритмическая сложность решения
Число рёбер в графе (точнее O(V + E)).
